## 一句话定位

把开源模型跑在自己机器上，换取数据不出本地、无调用成本、可离线。
代价是能力上限和速度都受硬件限制。

## 两个常用选择

**Ollama**：命令行驱动，适合脚本化和被其他程序调用。

```bash
ollama run qwen3
```

**LM Studio**：图形界面，适合试模型、调参数、对比不同量化版本的效果。

## 什么时候值得用

- 数据不能离开本机（内部代码、客户资料）
- 需要大量、低价值的重复调用，走 API 成本不划算
- 离线环境

## 什么时候不值得

{: .warn }
把本地模型当作云端模型的等价替代通常会失望。涉及长上下文、复杂推理、多文件改动的任务，
本地能跑动的模型和主流云端模型还有明显差距。

我的分工方式：**本地模型做分类、提取、改写这类结构化小任务，复杂推理交给云端**。

{: .tip }
显存是硬约束。选模型时先看量化版本能不能放下，再比较能力——放不下的模型没有意义。

{: .note }
具体模型名称和硬件要求变化很快，请以官方页面为准。
