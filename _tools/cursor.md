## 一句话定位

基于 VS Code 的 AI 编辑器。它的强项不是「替你接管整个仓库」，而是**在你正在看的那段代码附近**完成修改。

## 适合谁

- 主要工作方式是「对着文件边看边改」
- 需要补全、局部重写、小范围重构这类高频小操作
- 团队已有 VS Code 生态的配置和插件

## 我实际怎么用

**局部改写**：选中一段函数，直接描述要改成什么样。改动范围可控，一眼能看出对错。

**理解陌生代码**：选中一段逻辑问「这里的边界条件是什么」，答案的上下文就是选中的代码，不容易跑偏。

**小步重构**：提取函数、重命名、调整参数顺序这类操作，比开一个终端会话快。

## 注意事项

{: .warn }
补全类工具的产出默认是「看起来对」。涉及边界条件、并发、错误处理的代码，仍然要自己过一遍。

{: .tip }
把仓库级别的约定交给命令行 Agent 处理，把局部改动留给编辑器——两者分工比只用其中一个效率更高。
